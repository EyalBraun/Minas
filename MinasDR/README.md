# MinasDR (Data Receiver)

**Author:** Eyal Braun & Manus AI**Project:** Minas - Autonomous RC Car Telemetry & Security System

---

## 1. Overview

**MinasDR** is the base-station telemetry receiver. It listens via **ESP-NOW** for wireless telemetry packets broadcasted by the Minas RC car (**MinasDT**).

It is designed to build a professional-grade dataset for Machine Learning by:

1. **Ensuring Data Integrity:** Using a monotonic counter to detect and fill gaps in lost transmissions.

1. **Feature Engineering:** Calculating real-time driver "fingerprint" features like Jerk and Correlation.

1. **Centralized Logging:** Saving all sessions into a single master CSV file (`/minas_master_dataset.csv`) on an SD card.

---

## 2. ML Dataset Schema

The CSV generated by this receiver is ready for training without pre-processing:

| Column | Description | Why it matters for ML |
| --- | --- | --- |
| **Sequence** | Monotonic Counter | Ensures time-series continuity. |
| **Timestamp** | ms since car boot | Tracks the duration of driving patterns. |
| **Throttle** | Raw Input | Primary driver intent. |
| **Steering** | Raw Input | Primary driver style. |
| **Sonar** | Distance (cm) | Context (not used for ID, but for safety). |
| **PacketLost** | 0 or 1 | Flag to filter or handle missing data points. |
| **SteerJerk** | Delta Steering | Detects "smooth" vs "twitchy" drivers. |
| **ThrottleJerk** | Delta Throttle | Detects aggressive vs gradual acceleration. |
| **STCorr** | Steer-Throttle Corr | Detects cornering habits (braking in turns). |

## 3. Hardware Wiring (SD_MMC Mode)

| SD Module Pin | ESP32 Pin | Function |
| --- | --- | --- |
| **CLK** | GPIO 14 | SD Clock |
| **CMD** | GPIO 15 | SD Command |
| **D0** | GPIO 2 | SD Data 0 |
| **GND** | GND | Ground |
| **3.3V** | 3.3V | Power |

---

## 4. Setup Instructions

1. **Format SD:** Ensure your Micro SD card is formatted to FAT32.

1. **Upload:** Use PlatformIO to compile and upload the code to your base station ESP32.

1. **Monitor:** Open the Serial Monitor at 115200 baud to see live packet reception and logging status.
